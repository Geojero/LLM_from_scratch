## ⚡ Quick Start

1. Get an API key from [OpenAI](https://platform.openai.com) or [Google AI Studio](https://aistudio.google.com)
2. Create a `.env` file: `OPENAI_API_KEY=sk-your-key-here`
3. Start with `chapter_01_foundations/module_01_genai_landscape/01a_concept_what_is_genai.ipynb`
