## 🔥 Launch Sequence

```text
T-3  ➜  Get your API key
T-2  ➜  Configure the environment
T-1  ➜  Open the first notebook
T-0  ➜  🚀 LIFTOFF
```

1. **Get an API key** from [OpenAI](https://platform.openai.com) or [Google AI Studio](https://aistudio.google.com)
2. **Create a `.env` file** in the project root:
   ```env
   OPENAI_API_KEY=sk-your-key-here
   ```
3. **Begin your journey** with:
   ```
   chapter_01_foundations/module_01_genai_landscape/01a_concept_what_is_genai.ipynb
   ```
