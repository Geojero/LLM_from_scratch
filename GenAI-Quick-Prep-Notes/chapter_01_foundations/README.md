# 📚 Chapter 01: Foundations of GenAI & LLMs

## 🎯 Learning Objectives
After this chapter, you will:
- Understand what Generative AI is and how it differs from Traditional AI
- Know the current LLM landscape (closed vs open models)
- Understand the Transformer architecture (intuition, not math)
- Be able to make your first LLM API calls
- Know essential vocabulary: tokens, embeddings, temperature, context window
