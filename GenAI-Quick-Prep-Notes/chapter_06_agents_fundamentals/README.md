# 🤖 Chapter 06: AI Agents Fundamentals

## 🎯 Learning Objectives
- Understand what AI agents are and how they differ from chains
- Implement the ReAct (Reason + Act) pattern
- Build agents that use tools (search, calculate, API calls)
- Understand function calling / tool calling
- Master the agent decision loop

## 📖 Modules

### Module 01: What Are Agents?
- Chains vs Agents mental model
- The ReAct pattern (Thought → Action → Observation → Repeat)
- Agent architectures: single agent, router, orchestrator

### Module 02: Tool Calling
- OpenAI function calling
- LangChain @tool decorator
- Custom tool creation
- Structured tool inputs/outputs
- Error handling in tool calls
